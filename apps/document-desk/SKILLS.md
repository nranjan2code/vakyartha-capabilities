# Skills: Document Desk

- `document-desk-reader` (ships with this app): answers questions from the person's documents. It searches with `search_documents`, reads with `read_document` before answering, and cites the document and section. It only reads.
- `interactive-ui` and `surface-design` govern any chat surfaces made from search results.

The app itself needs no skill to run: syncing, conversion and search are ordinary code with no model.

The packaged assistant skill uses checked domain steps for its declared tools and interpretation. Vakyartha supplies the shared presentation procedure over retained results; this skill does not author report layout. Text requests remain text, and proposal writes still require the existing permissions and personal review.
