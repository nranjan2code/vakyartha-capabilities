# Skills and tools

The Vakyartha `app-authoring` and `app-maintainer` skills describe building and reviewing the package. Use `app-operator` and `app-debugger` to inspect host execution and failed imports, and `presentation` for evidence, accessible views and spoken summaries.

The app uses no model skill or external integration. Its two read-only exports supply scope and capture evidence to the Workbench after host access review. Manual collection uses the explicitly invoked terminal helper; imports, sorting, triage and summaries run as ordinary app code. Host voice playback uses the person's voice settings. Skill instructions grant no access.
