# Video Studio

Create, edit and keep programmes played inside Vakyartha. Home, Shorts and You retain viewing queues, progress, Watch later and playlists. Creator Studio is a viewport-fitting editor with a source/media browser, retained preview, inspector and gridded timeline. Compact icon controls have names, tooltips and focus states; narrow windows switch focused panes.

## Create and edit

Create a project or import a saved programme from News Desk, Market Terminal or Weather Desk. Sources can be appended to the selected project through their declared read-only exports. Their scene words, pictures, charts, figures, attribution and available dates remain together. Imports are explicit snapshots; source refresh never silently replaces a reviewed library version. Missing or denied sources fail honestly.

Select a Storyboard row to preview that scene and put the playhead at its start. Add, reorder, duplicate or delete scenes and edit their headings and narration. Choose existing shared Media or explicitly import an image, audio or video file (20 MB input limit). Source bytes stay with Media; projects retain asset references and edit parameters. Select a clip to edit start, duration, source in, framing/focal point, gain, fades, mute, solo and looping. Timeline zoom, grids and snapping share one seconds scale. Drag clip centres to move, edges to trim; keyboard arrows move (Alt trims, Shift increases the step), Delete removes. Split at the playhead or remove and close a gap.

Undo/redo retains twelve edit snapshots; keep up to eight named checkpoints. Project edits autosave and survive reopening. Add to library explicitly accepts a snapshot; later working edits do not replace it. Remove remains a two-step action. Invalid saved items remain retained and can be removed only after review.

## Run and review

The host preview and full Watch use the same shared voice and timed playback owner. Prepare measures decoded narration through the existing voice cache; applying measured lengths adjusts linked generated scene visuals/captions and later placements. Source footage is not stretched. Review the timeline after measurement. Run, pause, stop, seek and loop use one host clock for video, original sound, narration, music and captions. Music supports fades and ducks beneath narration. A narration that exceeds its slot fails with an explanation; missing or undecodable media is not silently substituted. TTS and other selected provider operations retain their normal costs and approvals.

A Short is an independent portrait draft cut from the selected scene and intersecting media. Keep the opening, context and ending coherent. Its source identity is separate from its parent reference. Short narration is limited to 120 words at library acceptance; this is not a duration guarantee.

The assistant can save a complete programme draft or propose a revision to one scene using the shared assistant pipeline. Proposals remain unreviewed until personal acceptance. App code has no model capability.

## Bounds and output

At most 100 projects, 80 scenes each, 400 timeline clips, four hours on a timeline and 8 MB of project/history content; narration is bounded to 4,000 characters per scene. Preparation has a 256 MB source-media budget. Runtime depends on the selected voice and measured assets. Programmes stay local: no finished-video rendering/export, external posting, camera or screen recording. Shared Media deletion can make referenced assets unavailable; removing a project does not delete shared files.
