# Skills

- `video-creator` uses `get_creator_context` and selected declared source app exports to save a complete source-aware programme draft with `propose_video`, or a selected-scene proposal with `propose_edit`. Expected revisions are checked by the host. The selected Storyboard scene scopes a revision. Personal review accepts proposals and library snapshots.
- Shared `broadcast-programme` defines canonical scenes, plain spoken wording, attribution and the shared Listen/Watch contract. Timed composition and preparation are host capabilities.
- `interactive-ui` and `surface-design` guide public Projection components. `app-authoring`, `app-maintainer`, `app-debugger`, `app-operator` and `app-admin` own package and host workflows. Skills grant no tool authority.
