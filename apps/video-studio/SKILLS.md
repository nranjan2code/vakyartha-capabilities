# Skills

## Shared Vakyartha skills

- `broadcast-programme` defines programme scenes and the Listen and Watch presentation contract.
- `app-authoring` owns package authoring and reviewed publication. `app-maintainer`, `app-debugger`, `app-operator` and `app-admin` cover later changes and operation.
- `interactive-ui` and `surface-design` guide any additional app surfaces.

## Ships with this app

- `video-creator` reads the current Creator Studio contract, uses the selected source apps' declared read-only programme tools, and saves complete source-aware shows or shorts as drafts. It requires the shared `broadcast-programme` procedure. It does not grant access or publish content.

Skill names and descriptions are selected first; supporting skill text is loaded through `read_skill_file`. Skills describe procedures and do not grant tool authority. Keep this map aligned with `exports.skills` and the source tools in `app.json`.
