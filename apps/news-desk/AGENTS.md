# Working on News Desk

Read Building a Vakyartha app (Vakyartha's app-building guide, in the Vakyartha product documentation) first; this app follows its method. Then README.md, SKILLS.md and ARCHITECTURE.md here.

## Invariants

- Presentation uses only public Projection components and props (for example `stat.icon`, hero `stat`, `rangebar`, scrolling `stack`, background-image cards). A missing visual capability is added to Projection for every app, never drawn by this package.
1. `context.state` is the only owner: `feeds[]` (with `enabled` and `weight`), `newFeed`, `opml`, `filters`, `articles[]` (with `firstSeen`), `saved[]`, `topics[]`, `topicDraft`, `topic`, `story`, `images`, `channel`, `reads` (bounded reading signals), `lastSeenAt`, `health{}`, `receipts[]`, `problem`, `checkedAt`. Every run starts with `normalize()`, which accepts untrusted or older state and drops malformed records.
2. `view(state, now)` is pure and derives all seven surfaces from the same ranked stories. Records render through repeaters; regions are emitted only when they apply; empty and failed states say what to do.
3. Ranking stays explainable and reader-owned: weights, half-life, section levels, mutes and retention live in `tuning` and are shown on Preferences; every score part remains a named reason shown in compact caption text on each story preview. Grouping never merges reports' links or times, and never claims two reports are the same event beyond "grouped by shared headline words".
4. `feed.ts` is a bounded syndication parser: no DTD or entity declarations, balanced tags, credential-free HTTPS article and image URLs, canonical URLs without `utm_` parameters. Source markup never becomes executable UI; excerpts and headlines are escaped Markdown text.
5. Only `web__fetch_page` is called, at most 15 times per run. A failed feed records health and a receipt and keeps earlier articles with their original times.
6. The header owns refresh, listening and voice choice. The compact header channel selector binds `/channel` and `/channelOptions` on the top surface through manifest `voice.listen.selector`; do not duplicate it in page content. Channel is an app preference; scripts use ranked records and publisher text, never invented context. “First” means earliest among the saved reports, never first worldwide.
6a. `/spoken/bulletin` is a programme (`bulletin.ts` `programme()`): intro cue on the greeting, the top five headlines as short parts over the faint theme bed, the sting on the first story, up to twelve stories (three per section in a general bulletin), up to three followed topics, then every other section (three each) or fourteen more channel stories, outro on the sign-off. Each story is used once; length follows the feed. Breaking (`isBreaking`): new to News Desk within 30 minutes and published within 90, plus two or more publishers or a followed topic; at most two, leading, with "First seen N minutes ago". `ticker`: every unread ranked story (60). Manifest `voice.listen.live: 4` lets the host refresh during a show and merge; never add app-side playback or interruption logic. One part per story with its publisher image and attribution. Text is publisher wording with fixed connecting phrases; visual fields are the record's own title, image, publisher, time and link. `bulletin()` is the same parts joined for tools. Never add a second script store or app-side playback; Listen, Watch, music and pictures are the host's.
7. Preserve publisher images in all story/report/bookmark grids and the user’s image toggle. Previews are compact: four thumbnail leads, compact thumbnail story rows, direct section/topic choices and a paged section rail. Full excerpts and every original report remain in coverage. Following displays topic choices with an explicit Unfollow button per topic; discovered topics are dynamically calculated across headline entities, story clusters and publisher tags (requiring at least 3 matching articles, bounded to the top 8, excluding sections and followed topics). Do not turn routine feed rotation into a warning, discard off-page stories, add nested overview tabs or duplicate autosave buttons. Use public Projection `imageLayout: "thumbnail"` and `titleLines: 2` for previews; full headlines remain accessible and in coverage. No app-side renderer CSS overrides.
8. Sections uses four compact dropdowns with `presentation: "dropdown"` (Section with counts, Published, Publisher, Order); Reset appears for any non-default filter or empty result. Section edits preserve the other filters; top-page section shortcuts open the default section view.
9. Fields save as they change; buttons validate (Add feed, Import OPML, Follow, Unfollow).

## Change method

Change `server.ts`, `rank.ts` or `feed.ts`; run `node scripts/app-surfaces.ts`; leave `version` alone (the owner types the new version at the next release; `node scripts/version.ts --list` shows the app); update these four documents; run `node --test test/reference-apps.test.ts test/app-registry.test.ts test/app-mcp-integration.test.ts`. Run `node scripts/news-desk-check.ts` for all six views and every source/coverage sub-tab at 1440/1100/620/375 px, including actual sandbox actions and local browsing. For visual review replay a retained publisher snapshot with `--state <file>`. Check ranking changes against real feeds (several hundred current articles) and look at the grouped stories, not only the tests. With network and the sandbox helper, `node scripts/reference-apps-check.ts --live` checks live feeds and the views in WebKit.

## Hosted operation

The shared host supplies Background operation in this app and Operation Center; package views must not duplicate it or own timers. Start & keep running persists the choice and runs the declared startup-refresh handler now and whenever Vakyartha launches. Refresh remains a manual action; automatic timing uses the declared cron interval, a chosen host timer, or Manual only. Stopping background operation leaves manual actions and saved data available. Startup also runs in Manual only mode.

The host owns scheduling, serialized commits, bounded recovery and run receipts. A failed computation with no external calls receives up to three delayed retries; uncertain external effects block replay for exact-run review. Tools require this app’s explicit mode/tool/destination access; integration Off remains a ceiling, and execution needs an awake computer and running Vakyartha. Reviewed package updates stop background operation for renewed review. Playback observes saved programmes and never starts another refresh loop.

## Shared Access and package review

This package declares 1 integration tool. Its action requirements are listed in entitlements.toolActions; review tools and destinations in Access, with separate foreground/background choices. Source and domain preferences do not grant access. Keep saved records and source freshness separate from permission readiness.

The Vakyartha host owns the Access panel and permission reasons; Rust is the sole desktop grant writer. Do not add app permission dialogs/stores, permission-error regexes or global-Allow shortcuts. Skills and manifests confer no authority.

Review complete package source/fingerprints and the access delta before updating. Preserve domain data, stop Background and review access for the changed package; do not blindly update packages or edited/disabled/removed skills. Ask currently blocks for in-panel review, not a waiting sandbox approval. Follow the root docs/features/APP-ACCESS.md contract, including shared stdio/native-audit limitations and independent source/outcome gates.

The manifest marks every declared tool with a plain-language purpose and optional/needed status. `renderApp(context)` is this package’s effect-free update projection: it reads retained copies and returns the same canonical views without source calls. The host discards renderer state/database mutations, refuses a failed rebuild and keeps the original package/data/views.


## Interaction and refresh cost

The shared Apps host retains its header and assistant dock across view changes and reconciles only changed canonical views after actions or background refresh. Local search and paging stay in the surface. Field handlers save normalized drafts without external reads. Return all views affected by a domain change, including spoken projections. Prefer a focused update for a draft with no other consumers and preserve saved computed values. Keep SQL and source calls for operations that need them. Each app retains its own contained worker across successful commands. Keep running controls hosted scheduling and restart eligibility. Durable state belongs in host checkpoints. Measure saved-data clicks, draft saves, source refresh and cold open separately before claiming a latency improvement.

The packaged assistant skill uses checked domain steps for its declared tools and interpretation. Vakyartha supplies the shared presentation procedure over retained results; this skill does not author report layout. Text requests remain text, and proposal writes still require the existing permissions and personal review.
