# Maintain Azure Infrastructure Workbench

Read README, ARCHITECTURE, SKILLS and the catalog rules.

- The Operations Desk owns captured data and subscription registrations. Workbench may retain copies of the selected two read observations and owns only its local plans. Verify both tenant and subscription on every scoped read. Switching scope cannot keep the old capture visible.
- Compare only complete observations of the same subscription. Use precise wording for control-plane visibility. Keep source timestamps, receipt rows and spoken values tied to the same records.
- Findings need traceable evidence. Changes to approved migration inputs reopen assessment. Validate dependency ordering, cycles, prerequisite stages and evidence before changing gates. Assessment imports apply as a batch.
- Use the shared host controls, local tables and tabs, and explicit CSV export. No timers, network requests or permission stores.
- Generate the empty view file from the renderer. Check scope changes, issue visibility, portal or pipeline handoff evidence, cutover gates, export and populated wide and narrow WebKit layouts. Keep the four documents in sync with the app.
