# Weather codes

Open-Meteo's `weather_code` uses the WMO 4677 codes below. Use these words; do not add detail the code does not carry.

| Code | Plain words |
|---|---|
| 0 | Clear sky |
| 1 | Mainly clear |
| 2 | Partly cloudy |
| 3 | Overcast |
| 45 | Fog |
| 48 | Freezing fog |
| 51 | Light drizzle |
| 53 | Drizzle |
| 55 | Heavy drizzle |
| 56 | Light freezing drizzle |
| 57 | Heavy freezing drizzle |
| 61 | Light rain |
| 63 | Rain |
| 65 | Heavy rain |
| 66 | Light freezing rain |
| 67 | Heavy freezing rain |
| 71 | Light snow |
| 73 | Snow |
| 75 | Heavy snow |
| 77 | Snow grains |
| 80 | Light rain showers |
| 81 | Rain showers |
| 82 | Violent rain showers |
| 85 | Light snow showers |
| 86 | Heavy snow showers |
| 95 | Thunderstorm |
| 96 | Thunderstorm with light hail |
| 99 | Thunderstorm with heavy hail |

A daily `weather_code` is the most severe condition of that day, not the whole day's weather: "rain at some point" rather than "rainy all day".
