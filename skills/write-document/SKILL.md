# Formal Document Drafting

## Steps

1. **brief**: Identify the document type, purpose, audience, requested language and locale, and the supplied facts. List the facts still missing that the document needs, such as names, dates, amounts or addresses.
2. **draft**: Write the document with a clear structure for its type. Use only supplied facts. Put each missing fact in square brackets, such as [recipient name], and never invent it.
   - needs: brief

## Domain guidance

A formal document is judged by its structure, accuracy and fit for the reader. Choose the conventions of the requested language and locale, not those of one country.

## Structure

- Use the conventional parts of the document type: a letter has a sender block, date, recipient, salutation, body and closing; a proposal has a summary, scope, plan, costs and terms; a report has a summary, findings and recommendations.
- Keep sections short and labelled. Use the headings that a reader of that document type expects.

## Locale conventions

- Write dates, numbers, currency and units in the format the requested locale uses, and keep the source values exact.
- Choose address forms, titles, salutations and closings that suit the language and the relationship. Ask when the relationship is unclear.
- Use the paper or page size and address layout typical of the locale only when the user asks for print layout.

## Rules

- Never invent facts, signatures, reference numbers, legal clauses or figures. Leave a bracketed placeholder instead.
- Flag any statement that needs a legal, financial or medical check before it is sent.
- Give the final text, then a short list of the placeholders the user must fill.
